# Drag-and-Drop Form Builder

A responsive, beginner-friendly form builder built with React and raw CSS. This tool allows users to create custom forms by dragging and dropping components like text fields, dropdowns, tables, and file uploads. It supports conditional logic, live previews, and mobile-friendly layouts.

## 🚀 Features

- 🧩 **Drag-and-drop interface** to build and reorder form components
- ✏️ **Editable fields** with custom questions and logic
- 🔁 **Conditional logic** for dropdowns (e.g., jump to a specific question)
- 📄 **Preview mode** in a new window
- 🧱 **Responsive design** for both desktop and mobile devices
- ♻️ Built with clean, minimal code using **React** and **vanilla CSS**

## 🧰 Components Supported

- Text Input (with optional min/max length)
- Dropdown (with custom options and logic)
- Table (add text or dropdown columns)
- File Upload

## 📦 Getting Started

1. **Install Node.js** if you haven’t: [https://nodejs.org](https://nodejs.org)
2. **Clone or unzip** the repository
3. Open terminal in the project folder and run:

```bash
npm install
npm start
````
